Houspire Planning Checklist

Pre-Design
- Measure each room (length, width, height).
- Note window and door positions.
- Capture photos from all corners.
- List must-keep furniture and items.

Design Preferences
- Choose a primary style direction.
- Pick 2-3 reference images per room.
- Define a color temperature preference.
- Note any material allergies or dislikes.

Execution
- Confirm timeline expectations.
- Set a contingency budget (5-10%).
- Align on contractor availability.
